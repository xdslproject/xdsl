Welcome to the xDSL documentation. xDSL is a Python-native compiler framework for
building and transforming intermediate representations.

- [Getting Started](guides/getting-started.md): set up xDSL and make your first
  contribution.
- [MLIR Interoperation](guides/mlir_interoperation.md): use xDSL with MLIR.
- [Constraint System](guides/constraints.md): define and constrain operations and
  attributes.

For hands-on examples, explore the [Tutorial Notebooks](notebooks/index.md).
For details of the Python APIs, see the [API Reference](reference/index.md).

Visit the [xDSL website](https://xdsl.dev/) for an overview of the project, blog
posts, and events.
